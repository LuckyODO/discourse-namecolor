# Discourse Name Color

Discourse Name Color 是一个 Discourse 主题组件，用于按“指定用户”和“群组成员关系”给用户名上色。

安装后默认不会改变任何名称颜色。只有添加了用户规则、群组规则，或主动启用内置群组色板后，组件才会开始改变显示效果。

## 颜色优先级

颜色按以下顺序计算：

1. 指定用户颜色
2. 指定群组成员颜色
3. 可选的内置群组色板
4. Discourse 原始样式

指定用户颜色永远拥有最高优先级。只要用户命中用户规则，即使他的主群组发生变化，也不会跟随群组颜色改变。

## 组件设置

可在主题组件控制面板里配置：

- `user_color_rules`：指定用户名和颜色或渐变，优先级最高。
- `group_color_rules`：指定群组名称和颜色或渐变，例如 `trust_level_1`。
- `use_default_group_palette`：为没有自定义颜色但已暴露在页面上的群组使用内置稳定色板，默认关闭。
- `apply_to_mentions`：将指定用户颜色应用到帖子中的 @提及，默认开启。
- `make_colored_names_bold`：让已着色名称略微加粗，默认关闭。

颜色支持安全的 CSS 颜色值和 CSS 渐变，例如：

- `#e53935`
- `rgb(229 57 53)`
- `hsl(210 60% 45%)`
- `var(--tertiary)`
- `linear-gradient(90deg, #e53935, #1e88e5)`
- `radial-gradient(circle, #ffca28, #e53935)`

## 生效范围

群组颜色会优先使用 Discourse 已暴露的群组信息；当页面上只看到用户名时，组件会按当前页面出现的用户名查询已配置群组的成员关系，再应用颜色。

指定用户颜色按用户名匹配，可更广泛地应用到用户链接和 @提及。由于主题组件不修改后端数据模型，如果某个群组的成员列表对当前访问者不可见，组件无法确认成员关系；这种情况下会保留 Discourse 原始样式或使用页面上已经暴露的群组信息。
