# Discourse Name Color

Discourse Name Color 是一个 Discourse 主题组件，用于按“指定用户”和“主群组”给用户名上色。

安装后默认不会改变任何名称颜色。只有添加了用户规则、群组规则，或主动启用内置群组色板后，组件才会开始改变显示效果。

## 颜色优先级

颜色按以下顺序计算：

1. 指定用户颜色
2. 指定群组颜色
3. 可选的内置群组色板
4. Discourse 原始样式

指定用户颜色永远拥有最高优先级。只要用户命中用户规则，即使他的主群组发生变化，也不会跟随群组颜色改变。

## 组件设置

可在主题组件控制面板里配置：

- `user_color_rules`：指定用户名和颜色，优先级最高。
- `group_color_rules`：指定主群组名称和颜色。
- `use_default_group_palette`：为没有自定义颜色的主群组使用内置稳定色板，默认关闭。
- `apply_to_mentions`：将指定用户颜色应用到帖子中的 @提及，默认开启。
- `make_colored_names_bold`：让已着色名称略微加粗，默认关闭。

颜色支持安全的 CSS 颜色值，例如：

- `#e53935`
- `rgb(229 57 53)`
- `hsl(210 60% 45%)`
- `var(--tertiary)`

## 生效范围

群组颜色会在 Discourse 已暴露 `primary_group_name` 的位置生效，包括帖子作者名、用户卡片和用户活动帖子列表等。

指定用户颜色按用户名匹配，可更广泛地应用到用户链接和 @提及。由于主题组件不修改后端数据模型，如果某个页面没有暴露用户主群组，群组颜色不会强行猜测；但指定用户颜色仍会尽可能按用户名应用。
